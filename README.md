# Refresher in Matrix Analysis and Numerical Optimization

**Master 2 MSIAM / MOSIG / Data Science** — Univ. Grenoble Alpes / Ensimag — *(EN)*

This repository contains the Python material for the refresher course in matrix analysis and numerical optimization. The lecture notes and exercise sheet are available on the [course page](https://enhamza.github.io/teaching/).

## Contents

| Notebook | Description |
|----------|-------------|
| [`Practical_Session_Optimization.ipynb`](Practical_Session_Optimization.ipynb) | Practical session: Numerical optimization in Python |
| [`python/Python_Basics.ipynb`](python/Python_Basics.ipynb) | Introduction to Python: syntax, types, control flow, functions |
| [`python/Python102_Numpy_and_co.ipynb`](python/Python102_Numpy_and_co.ipynb) | Scientific Python: NumPy, linear algebra, Matplotlib |

If you are new to Python, start with the two notebooks in `python/` before the practical session.

## Getting started

You need Python 3 with `numpy`, `matplotlib` and `jupyter`:

```bash
pip install numpy matplotlib jupyter
jupyter notebook
```
